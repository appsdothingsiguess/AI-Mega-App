# Retired AI Mega App harness

This directory preserves the former browser chat/agent harness after the
Pi.dev pivot. It is retained for rollback and historical reference, not as the
active application path.

The surviving repository surface is intentionally limited to configuration,
GPU inventory/swap generation, operational scripts, the Pi memory service, and
related service tests. The inference engine itself lives outside this
repository at `/home/john/llm-stack/engine` and was not moved or modified.

Preservation point: `pre-harness-retirement-2026-09-06`.
